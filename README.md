# Paradise Nursery Shopping Cart

A dynamic web application for Paradise Nursery, an online plant shop. Built with React and Redux.

## Project Name
**Paradise Nursery** – Your online destination for beautiful houseplants.

## Features
- Browse 18+ unique houseplants across 3 categories
- Add to cart with real-time cart count
- Adjust quantities and remove items
- View total cost per item and overall cart total
- Responsive navigation with Home, Plants, and Cart links

## Tech Stack
- React 18 + Vite
- Redux Toolkit (cartSlice with addItem, removeItem, updateQuantity)
- CSS3 with custom properties

## Getting Started
```bash
npm install
npm run dev
```
